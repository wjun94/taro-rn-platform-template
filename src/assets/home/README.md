# 首页图片素材

- 店铺横幅、活动海报及大部分商品照片根据首页参考图重新生成，为本地演示素材，不是线上商品数据。
- 页面使用压缩后的 JPEG，随应用分发，不依赖第三方图片外链。
- `icons/` 来自 Tabler Icons PNG 3.34.1，按页面配色调整，并缩小到 96×96。原项目：https://github.com/tabler/tabler-icons 。MIT 授权原文见 `icons/LICENSE`。
- `shoes.jpg` 使用 Unsplash 的鞋类摄影，来源：https://images.unsplash.com/photo-1549298916-b41d501d3772 ，授权说明：https://unsplash.com/license 。
- 后续接入真实商品时，在 `src/pages/index/data.ts` 替换对应素材和展示数据。
